# Assignment 2: Customer Loyalty Rewards System

## Objective
Design and build an application using AI tools. You are graded not only on whether it works, but on the decisions you make, how you direct the AI, and how you catch and fix its mistakes. You may use any AI tools you like, but you must be able to explain every part of your submission.

## Requirements
The client is the owner of a factory that produces physical products sold in boxes. They want a reward system to increase customer loyalty. Design and develop a system for this client.

You are free to assume any gaps in the requirements, but you must document every assumption in `ASSUMPTIONS.md`.

Your design must address:
* How a customer proves they bought a product
* How fraud and code reuse are prevented
* How the factory owner views, manages, and monitors rewards

## Repository Requirements

| File / Item | What it must include |
| :--- | :--- |
| **README.md** | What the app does, tech stack, setup and run instructions, and a deployed link if available |
| **ASSUMPTIONS.md** | Every gap you filled and why you chose that option |
| **AI_LOG.md** | 5 to 10 key prompts or interactions, including at least 2 cases where the AI was wrong, how you noticed, and how you fixed it |
| **ARCHITECTURE.md** | Stack choice with reasons, data model, and at least one diagram |
| **Tests** | Automated tests, or a documented manual test plan with results |
| **.env.example** | Placeholder values only. Never commit API keys, passwords, or secrets. |
| **Commit history** | Regular, meaningful commits showing how the project evolved. A single commit of the final code will lose marks. |

## Submission Rules
* Submit the link to one public GitHub repository.
* The repository must be accessible without login.
* You may be asked to attend a short live demo.
